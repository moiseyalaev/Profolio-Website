Thesis

Why I sit between software engineering and machine learning.

A

Evals are the test suite.

A model change is a deploy. I gate upgrades behind labeled evals, offline replay and shadow traffic, the same way I'd gate any risky release.

B

Data rots quietly.

I built a Go and gRPC pipeline that watches millions of sensor readings for stale data, because a model trained on a stuck sensor is confidently wrong.

C

Agents earn their autonomy.

I gave our Slack AI agent tools for Snowflake and Datadog plus a triage playbook, so it investigates first and escalates only real bugs. Escalations fell about 60%.
